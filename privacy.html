Политика конфиденциальности

Приложение «naklad» (внутренний Telegram-бот для загрузки накладных). Обновлено: 07.10.2026

1. Для кого это приложение

Приложение используется только сотрудниками компании для загрузки накладных поставщиков в Google Диск компании. Это не публичный сервис: доступ выдаёт администратор.

2. Какие данные Google используются

Приложение получает доступ к Google Диску только одного рабочего аккаунта компании, чтобы:

  • находить и создавать папки для накладных (год / месяц / день);
  • загружать в эти папки файлы накладных;
  • перемещать в корзину файл, который сотрудник загрузил по ошибке (только по его запросу).

Приложение не читает содержимое других файлов, не отправляет письма и не использует данные Google для рекламы, аналитики или обучения моделей. Данные Google не передаются третьим лицам.

3. Какие ещё данные хранятся

  • Telegram ID, имя и username сотрудников, которым выдан доступ, а также заявки на доступ;
  • журнал загрузок: какой файл, когда и кем загружен или удалён;
  • служебный журнал работы бота (для поиска ошибок).

Эти данные хранятся только на компьютере, на котором работает бот, и используются исключительно для его работы и контроля доступа.

4. Временные файлы

Фото и PDF накладных временно сохраняются на компьютере с ботом только на время загрузки и удаляются сразу после неё или после отмены.

5. Отзыв доступа

Владелец рабочего Google-аккаунта может в любой момент отозвать доступ приложения на странице myaccount.google.com/permissions.
