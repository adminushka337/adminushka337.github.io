naklad

Внутренний Telegram-бот для сотрудников

Бот помогает сотрудникам загружать накладные поставщиков в Google Диск компании: принимает фото и PDF, при необходимости склеивает несколько листов в один PDF, называет файл по единому стандарту и раскладывает по папкам «год / месяц / день».

Бот предназначен только для внутреннего использования. Доступ выдаётся администратором по заявке, посторонние пользователи бот использовать не могут.
